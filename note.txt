--- DAY 8 ---
1. paham konsep dasar react
    a. component = balok lego (setiap bagian UI), agar dapat di pakai berulang
    b. app = susunan lego lengkap
    c. state = kondisi balok (watna, ukuran), agar data dapat berubah didalam component
    d. props = data yg dikirim antar balok, agar data dapat di kirim ke child dari parent
    e. menggunakan JSX untuk HTML di dalam JS
    f. hooks = fufngsi khusus react sesuai kebutuhan (useState, useEffect, dll)

2. setup react dengan vite
    a. vite = build tool modern untuk react yg jauh lebih cepat dari create react app
    b. langkah setup
        - buat struktur folder (npm create vite@latest "nama_folder" -- --template react). --template react untuk menggunakan template react
        - masuk folder yg sudah dibuat
        - install depedencies (npm install)
        - tes react (npm run dev)
        - cek di packaege.json

3. install tailwind css (ini untuk installasi ver 4)
    - tailwind css = framework css utility-first untuk styling cepat
    - install packaege tailwind dan vite difolder yg dibuat npm install -D tailwindcss @tailwindcss/vite
    - update file viteconfig.js (tambah import tailwindcss dan masukan ke array plugins)
    - update drc/index.css (hapus semua dan ganti dengan @import "tailwindcss";)
    - test tailwind (buat function di src/App.jsx dengan code bebas)
    - cek di packaege.json

4. install react Router
    - install react router (npm install react-router-dom)
    - cek di packaege.json

5. install axios
    - axios = library untuk HTTP request ke API backend
    - npm install axios
    - cek di packaege.json

    3c. Buat Provider (ThemeProvider)
    State theme dengan lazy initializer → ambil dari localStorage.getItem('theme') || 'light'
    useEffect:
    Simpan theme ke localStorage
    Jika theme === 'dark' → document.documentElement.classList.add('dark')
    Else → document.documentElement.classList.remove('dark')
    Fungsi toggleTheme → setTheme(theme === 'light' ? 'dark' : 'light')
    value = { theme, toggleTheme }
    Return <ThemeContext.Provider value={value}>{children}</ThemeContext.Provider>

    4d. Custom Hook (useTheme)
    const context = useContext(ThemeContext)
    Cek jika !context → throw Error
    Return context

7. src/hooks/useTasks.js
    a. Import
    useState, useEffect dari 'react'
    api dari '../services/api'

    b. State
    tasks → array data task
    loading → status loading
    error → pesan error

    c. Fungsi fetchTasks()
    Set loading = true
    api.get('/tasks') → ambil semua task
    Simpan ke setTasks(response.data.data)
    Catch error → setError
    Finally → setLoading(false)

    d. Fungsi createTask(taskData)
    api.post('/tasks', taskData) → buat task baru
    Tambahkan ke state setTasks([newTask, ...tasks])
    Return { success: true, data }
    Catch → return { success: false, message }

    e. useEffect
    Jalan sekali saat mount → panggil fetchTasks()

    f. Return
    { tasks, loading, error, fetchTasks, createTask }
