--- DAY 8 ---
1. paham konsep dasar react
    a. component = balok lego (setiap bagian UI), agar dapat di pakai berulang
    b. app = susunan lego lengkap
    c. state = kondisi balok (watna, ukuran), agar data dapat berubah didalam component
    d. props = data yg dikirim antar balok, agar data dapat di kirim ke child dari parent
    e. menggunakan JSX untuk HTML di dalam JS
    f. hooks = fufngsi khusus react sesuai kebutuhan (useState, useEffect, dll)

2. setup react dengan vite
    a. vite = build tool modern untuk react yg jauh lebih cepat dari create react app
    b. langkah setup
        - buat struktur folder (npm create vite@latest "nama_folder" -- --template react). --template react untuk menggunakan template react
        - masuk folder yg sudah dibuat
        - install depedencies (npm install)
        - tes react (npm run dev)
        - cek di packaege.json

3. install tailwind css (ini untuk installasi ver 4)
    - tailwind css = framework css utility-first untuk styling cepat
    - install packaege tailwind dan vite difolder yg dibuat npm install -D tailwindcss @tailwindcss/vite
    - update file viteconfig.js (tambah import tailwindcss dan masukan ke array plugins)
    - update drc/index.css (hapus semua dan ganti dengan @import "tailwindcss";)
    - test tailwind (buat function di src/App.jsx dengan code bebas)
    - cek di packaege.json

4. install react Router
    - install react router (npm install react-router-dom)
    - cek di packaege.json

5. install axios
    - axios = library untuk HTTP request ke API backend
    - npm install axios
    - cek di packaege.json

6. buat struktur folder
    - src/
        ├── assets/              # Gambar, icon
        ├── components/          # Komponen reusable
        │   ├── Button.jsx
        │   ├── Input.jsx
        │   └── Navbar.jsx
        ├── pages/               # Halaman
        │   ├── Login.jsx
        │   ├── Register.jsx
        │   ├── Dashboard.jsx
        │   └── NotFound.jsx
        ├── services/            # API service
        │   └── api.js
        ├── contexts/            # React Context (nanti)
        │   └── AuthContext.jsx
        ├── hooks/               # Custom hooks (nanti)
        ├── utils/               # Helper functions
        ├── App.jsx              # Main app
        ├── main.jsx             # Entry point
        └── index.css            # Global CSS
    - cara buat folder mkdir "nama_folder"

7. buat komponen pertama
    - buat file src/services/api.js (untuk konfigurasi API)
    - buat file src/components/Button.jsx (untuk komponen button reusable)
    - buat file src/pages/Dashboard.jsx (untuk halaman sederhana tes)
    - update src/App.js (impoer component dashboard dan di return panggil component yg dibuat)
    - tes di browser (npm run dev)

8. commit dan push
    - masuk di folder yg dibuat 
    - git init 
    - git add .
    - git commit -m "pesan yg dimasukan"
    - buat repo di github
    - git branch -M main
    - git remote add origin "link_repo_github"
    - git push -u origin main 
    - disarankan memiliki min 3 branch untuk main (prod), develop (staging), feature/xxx (untuk udpate fitur)

9. penjelasan dasar direktori folder
  src/
  ├── assets/         # Gambar, icon, font
  ├── components/     # Komponen reusable (Button, Input, dll)
  ├── contexts/       # React Context (AuthContext, dll)
  ├── hooks/          # Custom hooks (useAuth, dll)
  ├── pages/          # Halaman (Login, Register, Dashboard)
  ├── services/       # API service (api.js)
  └── utils/          # Helper functions

10. hubungan antar file
  main.jsx  (entry point, dari Vite)
      │
      ▼
  App.jsx  (root component)
      │
      ├── Import Dashboard
      │
      ▼
  pages/Dashboard.jsx  (halaman)
      │
      ├── Import Button
      │
      ▼
  components/Button.jsx  (komponen reusable)

  ═══════════════════════════════════════════

services/api.js  (Konfigurasi Axios)
    │
    │ dipakai nanti di:
    ▼
pages/Login.jsx, pages/Register.jsx, dll

11. alur
  main.jsx render App
  App render Dashboard
  Dashboard pakai Button
  Button punya style Tailwind

12. file untuk api
  services/api.js  (konfigurasi axios)
    │
    └── Dipakai di halaman (Login, Dashboard, dll)
        untuk request ke backend
